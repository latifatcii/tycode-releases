# TYCode releases

Packages of TYCode, an IDE where agents build, run and debug with you.

Download the newest release from the [releases page](https://github.com/latifatcii/tycode-releases/releases/latest). On macOS with Apple silicon, open `TYCode-darwin-arm64.dmg` and drag TYCode to Applications.

An installed TYCode looks here for newer releases and offers them as an update.
